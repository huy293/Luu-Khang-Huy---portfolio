## ⚡ Hướng Dẫn Chạy Cục Bộ (Local Setup)

Bạn có thể xem trước trang web portfolio trực tiếp bằng bất kỳ static server nào:

```bash
# Sử dụng Python built-in HTTP server
python -m http.server 8080

# Hoặc dùng Node.js npx serve
npx serve .
```

Truy cập: `http://localhost:8080/` hoặc `http://localhost:8080/portfolio_huy.html`.

## 🌐 Kích Hoạt GitHub Pages (Deployment)

1. Truy cập repo trên GitHub: `https://github.com/huy293/Luu-Khang-Huy---portfolio`
2. Vào **Settings** > **Pages**
3. Tại mục **Build and deployment** > **Source**, chọn `Deploy from a branch`
4. Chọn Branch `main` (hoặc `master`), thư mục `/ (root)` và nhấn **Save**
5. Trang web sẽ trực tiếp live tại URL: `https://huy293.github.io/Luu-Khang-Huy---portfolio/`
